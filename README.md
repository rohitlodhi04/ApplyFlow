\# ApplyFlow — Job Application Tracker



ApplyFlow is a job application tracking backend built with Django and Django REST Framework. It is designed to help users organize and track their job and internship applications.



\## Current Features



\- Django REST Framework API

\- Job application data model

\- API serializers and endpoints

\- JWT authentication

\- User-linked job applications



\## Tech Stack



\- Python

\- Django

\- Django REST Framework

\- Simple JWT

\- SQLite



\## Project Status



Backend development is in progress. Frontend integration and additional features will be added as the project develops.



\## Run Locally



1\. Clone this repository.

2\. Create and activate a Python virtual environment.

3\. Install the required dependencies.

4\. Apply database migrations.

5\. Start the Django development server.



```bash

python manage.py migrate

python manage.py runserver

```
